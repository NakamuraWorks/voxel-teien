# ボクセル日本庭園 — Voxel Teien

ボクセルで組んだ回遊式日本庭園を、一人称で歩き回るだけのアプリ。
地形も飛石も五橋も灯籠も木も水音も、その場で生成する。
唯一の置きファイルは `src/audio/庭の静けさと.mp3` で、自動ガイドと庭園周遊の BGM になる。

```
npm install
npm run dev        →  http://localhost:5173
```

「庭に入る」を押すと、総門の鳥居の前から歩き始められる。

## 操作

- マウスで視点 / `W A S D` で歩く / `Shift` 小走 / `Space` 跳ぶ
- `V` **自動ガイド** — 八つの見どころを約 168 秒で案内する（`Esc` で終了）
- `T` 日時計、`[` `]` 時刻、`C` 庭園周遊、`F` 空を飛ぶ
- `L` 灯籠、`M` 音、`H` HUD、`R` 総門へ戻る
- `- =` 全体の音量、`, .` BGM の音量（HUD 右下のスライダーでも可）

`V` の自動ガイドと `C` の庭園周遊のあいだだけ、BGM がフェードインでかかる。
手で歩いている間は、合成した風・水音・鳥や虫の声だけが残る。
スライダーはポインターロックを抜いた状態（`Esc` 後）で掴める。

イヤホンがあると、渓流の水音・風・昼の鳥・夜の虫まで再現される。

## その他

- `npm test` … ブラウザなしで生成・メッシュ・物理・自動ガイドの高低追従を検証（17 件）
- `npm run build` / `npm run preview` … 静的ビルド（JS 615 kB / gzip 162 kB + 音源 4.8 MB）

**実装を一通り歩いた記録は [WALKTHROUGH.md](./WALKTHROUGH.md) にある。**
生成の順番、面除去と AO のメッシュ化、飛石を昇る衝突判定、昼夜と水の作り込み、
ブラウザを実際に開けて直した不具合、テストで何を確かめているか、
どこを直せば別バージョンの庭になるかを、実測値付きで書いている。
